# chuantone_media

Plugin nội bộ của app ChuẩnTone (M7, `docs/m7-plan.md`): kênh `chuantone/media` gọi API native của
iOS — bảng chia sẻ (`UIActivityViewController`); về sau thêm dựng video sóng nhạc, camera trước, ghép
hình + tiếng (`AVFoundation`), lưu vào Ảnh (`Photos`). Android: chưa có (giai đoạn Android).
